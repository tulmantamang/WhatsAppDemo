# WhatsApp Demo 📱💬

A simple WhatsApp-inspired mobile application created as a learning project during my 6th semester Mobile Programming course.

## 📌 About Project

This project was developed to understand the fundamentals of mobile app development, user interface design, navigation, and messaging app layouts. It is a demo application inspired by the basic structure of WhatsApp.

## 🎓 Academic Purpose

Built as part of my **6th Semester Mobile Programming** learning journey to gain hands-on experience in mobile application development.

## 🚀 Features

* Chat list interface
* Contact/profile display
* Message screen layout
* Navigation between screens
* Basic mobile UI components
* Demo messaging structure
* Learning-focused implementation
